# BIOS / UEFI

Пути из Lenovo BIOS Simulator, линейка ThinkCentre.

## Задача 1. Виртуализация

Путь: **Config → CPU → Intel Virtualization Technology**. На AMD пункт называется **AMD-V** и лежит в **Advanced → CPU Setup**.

Сейчас стоит **Enabled**. Оставил как есть.

Пункт нужен для виртуальных машин: Hyper-V, VMware, VirtualBox, WSL2. Процессор сам выполняет гостевую систему. Если пункт выключен, машина не стартует или работает очень медленно.

## Задача 2. TPM и BitLocker

Путь: **Security → Security Chip** (или **Trusted Platform Module**).

Сейчас **Enabled**, это TPM 2.0. Если было Disabled, после включения нужна перезагрузка.

В чипе лежит ключ BitLocker. Пока TPM включён, Windows открывает диск сама. Если чип выключить, система спросит ключ восстановления. Без ключа диск не открыть.

## Задача 3. After Power Loss

Путь: **Power → After Power Loss** (иногда **AC Power Recovery**).

- **Power Off** — после света компьютер остаётся выключенным.
- **Power On** — включается сам.
- **Last State** — как было до отключения: работал, значит включится.

По умолчанию на ThinkCentre обычно **Power Off**. Я поставил Power On, потом вернул **Last State**.

Для сервера в дальней стойке ставят **Power On**: после аварии его некому включать кнопкой.

## Задача 4. Secure Boot

Путь: **Security → Secure Boot**.

Переключил в **Disabled**. Появилось предупреждение: можно загрузить неподписанный загрузчик. Рядом смотрятся **Secure Boot Status**, **Platform Mode**, **Secure Boot Mode**. При включении обычно User Mode и Standard. При выключении — Setup Mode. Потом вернул **Enabled**.

Выключают в двух случаях: загрузка с неподписанной флешки и установка Linux, если прошивка не принимает её загрузчик.

## Задача 5. Fast Boot

Путь: **Startup → Fast Boot**.

Выключил и открыл меню F12. Флешка появилась в списке загрузки. Потом снова включил Fast Boot.

При Fast Boot прошивка короче проверяет устройства и часто не успевает увидеть USB. Загрузочная флешка при этом исправна, её просто не инициализировали.

## Задача 6. Power-On Password

Путь: **Security → Password → Power-On Password**.

Поставил пароль `Boot1234` и сохранил выход (F10). При следующем входе пароль спросили до загрузки системы. Сброс: ввести текущий пароль и оставить новый пустым.

**Power-On Password** спрашивают при каждом включении, до Windows. Нужен, если к компьютеру есть доступ у посторонних.

**Supervisor Password** спрашивают при входе в BIOS. Система грузится, а настройки загрузки, Secure Boot и TPM поменять нельзя.

## Задача 7. Режим SATA

Путь: **Config → Storage → SATA Controller Mode**.

Варианты: **AHCI**, **RAID**, **Intel RST**. Было **AHCI**. Переключил на RAID, прошивка предупредила, что система может перестать грузиться. Вернул AHCI.

Windows ставили с драйвером AHCI. В режиме RAID контроллер для неё другой, диск не читается, загрузка падает. Файлы на диске остаются. Режим меняют до установки системы.

## Задача 8. Журнал событий

Путь: **Main → System Summary** или **Config → Diagnostics → Event Log**.

Там ошибки POST, перегрев, сбой загрузки, смена настроек. Открыл записи и нажал **Clear Event Log**.

Журнал чистят перед передачей компьютера другому человеку, чтобы старые ошибки не мешали новой проверке.

## Задача 9. Сброс

**Restart → Load Factory Defaults** возвращает пункты меню к заводским. Диск не стирает, пароли NVMe обычно не снимает. Этот сброс я подтвердил.

**Security → Reset System to Factory Defaults** глубже. В предупреждении просят сначала выключить Absolute Persistence и снять пароли NVMe. Этот пункт я не запускал.

Обычный сброс — когда сбились настройки. Полный — когда компьютер отдают другому человеку.

## Задача 10. Новый сотрудник

1. **Config → CPU → Intel Virtualization Technology** — Enabled.
2. **Security → Security Chip** — Enabled.
3. **Security → Password → Power-On Password** — пароль установлен.
4. **Startup → Fast Boot** — Disabled.
5. **Power → After Power Loss** — Power On.
6. F10, повторный вход: все пять пунктов на месте.

После проверки пароль снял и вернул Fast Boot во включённое состояние.
